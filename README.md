# 🏥 غيث للصحة - نظام المراقبة الشامل | Ghaith Health Monitor

تطبيق ويب متكامل لمراقبة الحالة الصحية، يقوم بتحليل وعرض **7 مؤشرات حيوية** أساسية لحظياً، مما يوفر نظرة شاملة عن صحة المستخدم.

## 📊 المؤشرات التي يتم قياسها (7 مؤشرات)

1.  **نبض القلب (Heart Rate):** قياس النبض في الدقيقة.
2.  **درجة الحرارة (Temperature):** مراقبة حرارة الجسم.
3.  **نسبة الأكسجين (Oxygen):** قياس مستوى الأكسجين في الدم.
4.  **ضغط الدم (Blood Pressure):** متابعة مستويات الضغط.
5.  **معدل التنفس (Respiratory Rate):** مراقبة أنفاس المستخدم.
6.  **النشاط البدني (Activity):** تتبع الحركة أو السعرات.
7.  **الحالة المزاجية/الإجهاد (Stress/Mood):** مؤشر إضافي للراحة النفسية.

## 🌟 مميزات المشروع

- **لوحة تحكم شاملة:** عرض الـ 7 مقاييس في واجهة واحدة منظمة.
- **تحليل فوري:** تحديث البيانات بشكل حي باستخدام JavaScript.
- **تصميم متجاوب:** يعمل بكفاءة عالية على الهواتف الذكية وأجهزة الكمبيوتر.

## 🛠️ التقنيات المستخدمة

- **HTML5 & CSS3:** لبناء وتنسيق البطاقات (Cards) والعدادات.
- **JavaScript:** المسؤول عن المنطق البرمجي وتحديث القيم السبعة.
